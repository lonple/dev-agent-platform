# Python 编码规范

| 项 | 内容 |
|---|---|
| 版本 | V1.0.0 |
| 适用 | Python 服务（如 FastAPI / dap-agent）及同类仓 |
| 原则 | 未写明跟仓库；冲突以本文为准 |

## 硬规则

1. **结构**：按包分层（`api` / `agents` / `tools` / `schemas` / `config`）；路由只做接入，业务与工具调用放下层。对齐邻接模块，不另起目录风格。
2. **类型与模型**：公开函数补类型注解；请求/响应用 Pydantic（或仓内等价）；禁止接口层裸 `dict` 到处传。
3. **异步与 HTTP**：已有 async 路径保持 async；对 Java/外部调用设超时；访问本机/内网服务时注意代理干扰（如 `trust_env=False`）。
4. **安全**：内部接口校验内部 Token；密钥只来自配置/环境变量，禁止写进代码或日志。
5. **日志与错误**：用 `logging` + 占位符；失败上抛或转成明确错误事件，禁止吞异常后假装成功。
6. **Agent**：只改任务相关文件；禁止无关重构与擅自加依赖；报告列出变更文件与验证方式。
