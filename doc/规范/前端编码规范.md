# 前端编码规范

| 项 | 内容 |
|---|---|
| 版本 | V1.1.0 |
| 适用 | Vue 3 + TypeScript 中后台 |
| 原则 | 未写明跟仓库；冲突以本文为准。视觉见《UI设计规范》 |

## 硬规则

1. **目录**：`api/` 只封装请求；`views/` 只拼页面；`stores/` 只放跨页会话态；`utils/request` 为唯一 HTTP 出口。禁止页面里 `axios.create`。
2. **写法**：`<script setup lang="ts">`；页面以 `View` 结尾；禁止无必要 `any`；类型复用 `types/` 或 api 导出。
3. **请求**：拦截器注入 Token / 租户；`api` 只返回业务 `data`；401 统一清会话跳登录；写操作必须 loading。
4. **权限**：路由 `meta` + 按钮按权限不渲染；判断走统一 store，不散落字符串。
5. **样式**：色值/间距用 Token；禁止页面硬编码色值。
6. **Agent**：只改任务相关文件；禁止无关重构与擅自加依赖；报告列出变更文件。
