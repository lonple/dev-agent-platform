# Java 编码规范

| 项 | 内容 |
|---|---|
| 版本 | V1.1.0 |
| 适用 | Java 21 + Spring Boot 中后台 |
| 原则 | 未写明跟仓库；冲突以本文为准 |

## 硬规则

1. **分层**：Controller 薄（入参/权限/响应）；业务在 Service；Mapper 只持久化。禁止 Controller 堆业务或直访 Mapper。
2. **API**：统一 `code/message/data`（成功 `code=0`）；业务失败抛统一业务异常；入参 `@Valid`。
3. **安全**：接口声明权限；多租户条件来自服务端上下文，查询/变更必须带归属条件；密钥/Token 禁止进日志。
4. **数据**：表变更走迁移脚本；写操作 Service 加事务；列表入口分页；禁止无 WHERE 更新删除。
5. **风格**：构造器注入；日志用占位符；禁止空 `catch`、`System.out`。
6. **Agent**：只改任务相关模块；禁止擅自加依赖/大版本升级；新接口必须带权限（若需）与租户条件；报告列出变更与自测要点。
