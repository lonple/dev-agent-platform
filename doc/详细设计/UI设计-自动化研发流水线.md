## 1. 设计原则

1. **不新开顶级菜单**；入口在「工作台 → 需求详情」顶栏。  
2. **点击后单开自动化工作台**（盖住需求详情的全屏层），不是详情内嵌折叠面板。  
3. **三套进度分区**：粗状态 / 手动任务 / 流水线，文案互不暗示门禁。  
4. **少卡片、少装饰**；时间线 + 节点详情 +（AI 时）执行栏。  
5. **同意整改 ≠ 取消**：有「同意」确认项才进整改再审；取消结束整条实例。项级「不同意」不是取消流水线。  
6. **按岗触发**：仅本岗可执行对应 AI 任务单元；他岗只读。兼岗则同一节点展示多个任务单元且均可触发。  
7. **PM 初审默认通过**：自动化内不停留；时间线保留「默认通过」标记。

## 2. 信息架构与导航

```text
侧栏工作台
├─ 需求列表（待办 | 全部）
└─ 需求详情
    └─ 顶栏「自动化流水线」──► 单开自动化工作台（全屏 overlay）
         ├─ 顶栏：返回需求 | 标题 | 实例状态 | 耗时/Token | 取消
         ├─ 流程概要条：定义 · 当前节点 · 等待原因 · 轮次
         ├─ 左：任务流程（时间线）
         ├─ 中：节点基本信息（I/O 文档、首次提示词、人闸）
         └─ 右：AI 执行过程（仅 AI 节点展开）
```

**不采用**：侧栏独立「流水线」菜单、设置里大菜单（定义管理另议）。

### 2.1 需求详情顶栏

| 条件 | 按钮 | 说明 |
|---|---|---|
| 始终（有权限） | **自动化流水线** | `primary`；打开单开工作台（未启动也可进，台内再「进入」） |
| 有实例 | （工作台内）取消自动化 | `danger` plain |
| 始终（现有） | 创建任务 / 审批类等 | 保持原逻辑 |

## 3. 界面：单开自动化工作台

### 3.1 线框

```text
┌─ ← 返回需求 | REQ-… 标题 | [等待确认] | 耗时 · Token | 刷新 | 取消 ─┐
├─ 定义 研发自动化 v1 | 当前 架构师确认初审 | 等待 人闸 | 轮次 1/3 ───┤
├────────────┬──────────────────────────┬────────────────────┤
│ 任务流程   │ 节点基本信息             │ AI 执行过程        │
│ ✓ …        │ 状态 / 类型 / 角色 / 轮次 │（选中 AI 步时出现）│
│ ► 架构师确认│ [输入文档] [输出文档]    │ user / tool / AI   │
│ ○ …        │ [查看首次提示词]         │                    │
│            │                          │                    │
│            │ 一类·确认项：同意/不同意 │                    │
│            │ 二类·疑似项：人类解答     │                    │
│            │ [提交确认]               │                    │
└────────────┴──────────────────────────┴────────────────────┘
```

### 3.2 与 6 点需求对照

| # | 需求 | 表现 |
|---|---|---|
| 1 | 查看任务流程 | 左栏可点时间线（含整改节点、轮次） |
| 2 | 当前流程基本信息 | 顶栏 + 概要条 |
| 3 | AI 节点看执行 | 选中 AI 步展开右栏会话流 |
| 4 | 输入/输出/首次提示词 | 中栏按钮 → 右侧抽屉只读预览 |
| 5 | 审批确认 | **两类项**见 §3.3（非笼统「有效项勾选」） |
| 6 | 提交后推进 | 有同意项→整改再审；否则→下一步 |

### 3.3 审批确认：两类项（对齐模板）

来源：[`评审模板.md`](../模板/评审模板.md) 的「问题清单 / 疑似问题」；[`原始需求评估模板-业务.md`](../模板/原始需求评估模板-业务.md) 的「业务风险 / 疑似问题」（技术评估同构）。

| 类型 | 模板章节（例） | AI 语义 | 人类动作 |
|---|---|---|---|
| **一类 · 确认项** | 问题清单；业务风险 / 技术风险 | AI **已认定**有问题，并给出建议（可多条）+ **推荐** | **同意 · 采纳推荐**；或 **不同意** 并填写「不同意意见 / 替代建议」 |
| **二类 · 疑似项** | 疑似问题 | AI **不确定**是否有问题，只抛出问题（可附参考建议） | **必须人类解答**（确认假设、选方案、补信息） |

```text
┌─ 一类 · 问题清单 / 业务风险 ─────────────────────┐
│ #2 未说明缓存失效策略                    [P1]   │
│ 建议：①TTL…；②一致性取舍…   推荐：①              │
│ [同意·采纳推荐]  [不同意]                        │
│ （若不同意）不同意意见：________________         │
└──────────────────────────────────────────────────┘
┌─ 二类 · 疑似问题 ────────────────────────────────┐
│ A1 AI假设「手机号全局唯一」                      │
│ AI 建议（参考）：在需求中确认…                   │
│ 人类解答（必填）：________________               │
└──────────────────────────────────────────────────┘
              [提交确认]
```

#### 提交规则

| 条件 | 结果 |
|---|---|
| 一类未全部表态，或不同意未填意见，或疑似未答完 | 不可提交（Toast 提示） |
| 存在 ≥1 条一类「同意」 | → **AI 整改**（Prompt 带入：同意项的推荐建议 + 不同意意见 + 疑似解答）→ 再回同一人闸 |
| 一类全部「不同意」、疑似已答 | → **下一步**（无需整改；不同意意见与解答仍可写入上下文/归档） |
| 顶栏 **取消自动化** | 整条实例结束（与项级不同意无关） |

> 不再使用「勾选有效项 + 通过/未通过」双按钮作为主交互；由项级表态 + 一次「提交确认」推导是否整改。

### 3.4 任务单元（多 Agent 节点）

适用于 **AI 初审** 等「一节点多 Agent」：

```text
节点：AI 初审
┌─ 任务单元 · 业务评审 ─ 产品 ─ [待执行] ─────────────┐
│ Agent：AI 产品经理 · 模板：原始需求评估-业务         │
│ [首次提示词] [查看执行]  [执行 Agent] ← 仅 PM/兼岗   │
└──────────────────────────────────────────────────────┘
┌─ 任务单元 · 技术评审 ─ 架构 ─ [待执行] ─────────────┐
│ Agent：AI 架构师 · 模板：原始需求评估-技术           │
│ [首次提示词] [查看执行]  [执行 Agent] ← 仅 ARCH/兼岗 │
└──────────────────────────────────────────────────────┘
（研发视角：两单元均可看，执行按钮禁用）
```

| 规则 | UI |
|---|---|
| 本岗 | 「执行 Agent」可用 |
| 他岗 | 按钮 disabled +「可看 · 不可触发」 |
| 兼岗 | 两单元都展示、都可触发（Mock 顶栏可选「同一人」） |
| 右栏执行过程 | 随当前聚焦的任务单元切换会话 |
| 节点离开 | 全部单元完成后才推进 |

PM 初审节点：中栏展示绿底说明「自动化流程内默认直接通过」，Tag `默认通过`。

### 3.5 状态徽章

| 实例状态 | Tag | 色 |
|---|---|---|
| 未启动 | 未启动 | info |
| RUNNING | 运行中 | primary |
| WAITING_HUMAN | 等待确认 | warning |
| DONE | 已完成 | success |
| CANCELLED | 已取消 | info |

步骤图标：`✓` 成功 / `►` 当前 / `○` 未到 / `!` 失败；整改步带「整改」小标。

### 3.6 交互要点

- 点时间线 → 中栏切节点；AI 步自动开右栏。  
- 多单元节点：中栏两张任务卡；「查看执行」切换右栏会话。  
- 顶栏演示视角：产品 / 架构 / 兼岗 / 研发（只读）。  
- 文档 / 首次提示词 → 抽屉只读。  
- 人闸仅当前 `WAITING_HUMAN` 可操作。

## 5. 关键文案

| 场景 | 文案 |
|---|---|
| 缺表态 | 请对所有「确认项」表态（同意或不同意） |
| 缺不同意意见 | 不同意项须填写不同意意见：#{id} |
| 缺疑似解答 | 请解答所有「疑似问题」：{id} |
| 提交→整改 | 提交确认 → 进入整改（同意 n 项 + 疑似解答已带入） |
| 提交→下一步 | 已确认，进入：{下一步} |
| 整改回来 | 整改完成 → 回到「{人闸}」再审（r{n}） |
| 达 max_round | 已达 max_round，请减少同意项或取消流水线 |
| 取消 | 确认取消自动化？进行中的步骤将停止 |
