#### TC-I-001 优惠券选择弹窗移动端滚动无遮挡

| 项 | 内容 |
|---|---|
| 关联AC | AC-04 |
| 优先级 | P1 |
| 测试方式 | 手工 |
| 为什么不能自动化 | 弹窗滚动流畅度、内容是否被底部操作栏遮挡，属于视觉与交互手感判断，机器难以稳定判定 |

| 检查点 | ☐ 滚动流畅 ☐ 无遮挡 ☐ 末项可见可点 |
| 备注 | 覆盖 iOS 和 Android 各一台设备 |
