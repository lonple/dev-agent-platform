### 约定
1. 模板内含**评审维度**；有效项挂在维度下的「有效评审项」任务列表。  
2. LLM **整份按模板输出**；平台解析所有 `#### 有效评审项` 下的 `- [ ]`/`- [x]`。  
3. 多角色共用同一模板文件，kickoff 指定本路 `评审角色`；确认页合并多路有效项供人编辑确认。
