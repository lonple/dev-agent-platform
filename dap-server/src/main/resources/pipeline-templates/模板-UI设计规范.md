## 2. 色彩 Token

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg-page` | 【#F7F8FA】 | 页面背景 |
| `--color-bg-surface` | 【#FFFFFF】 | 面板/表单底 |
| `--color-border` | 【#E5E7EB】 | 分割线、边框 |
| `--color-text` | 【#1F2329】 | 标题 |
| `--color-text-secondary` | 【#4B5563】 | 正文 |
| `--color-text-muted` | 【#8C8C8C】 | 辅助 |
| `--color-primary` | 【#2B5AED】 | 主按钮、当前节点、链接 |
| `--color-primary-hover` | 【#1E4BD6】 | 主按钮悬停 |
| `--color-primary-soft` | 【#EAF0FF】 | 选中底 |
| `--color-success` | 【#16A34A】 | 通过/完成 |
| `--color-warning` | 【#D97706】 | 等待/待办 |
| `--color-danger` | 【#DC2626】 | 驳回/失败 |

**规则**

- 强调色面积建议 ≤ 视觉面积约 10%；禁止大面积渐变底。  
- 状态不能只靠颜色，须配合文字或图标。  
- 【其他禁止项】

## 4. 间距 · 圆角 · 边线

| Token | 值 | 用途 |
|---|---|---|
| 间距基准 | 4px 网格 | — |
| `--space-2`～`--space-5` | 8 / 12 / 16 / 24 | 紧凑→区块 |
| `--radius-sm` | 4px | 按钮、输入、Tag |
| `--radius-md` | 8px | 面板、对话框 |

**规则**：主按钮不用全圆角 pill；卡片圆角不超过 【12px】。

## 5. 组件规范（摘要）

对每个用到的组件写「样式 + 状态」，勿写具体业务文案长篇。

### 5.1 按钮

| 类型 | 使用场景 | 样式要点 |
|---|---|---|
| Primary | 主行动（进入自动化、我确认） | 实心强调色 |
| Default | 次要 | 白底灰边 |
| Danger plain | 驳回、取消自动化 | 危色字+浅边 |
| Link | 表格行内 | 强调色文字 |

禁用须有原因（Tooltip）。【补充尺寸：默认高 28/32】

### 5.2 标签 Tag

| 语义 | 底/字色 | 示例文案 |
|---|---|---|
| 等待 | warning 底 | 等待确认 |
| 运行 | primary 软底 | 运行中 |
| 成功 | success 底 | 已完成 |
| 中性 | gray 底 | 未启动 |

### 5.3 表单

- 标签在上或左：【上】  
- 错误：字段下红字 + 边框 danger  
- 【其他】

### 5.4 抽屉 / 对话框

- 抽屉宽度：【约 480–560px】  
- 遮罩：【半透明深灰】  
- 页脚右对齐主按钮  

### 5.5 时间线 / 步骤条（若有）

- 当前节点：primary 软底 + ►  
- 完成：success ✓  
- 未到：灰 ○  
- 并行：缩进 + ∥  

### 5.6 表格

- 表头 gray-50；行高紧凑；操作列 link 按钮。
