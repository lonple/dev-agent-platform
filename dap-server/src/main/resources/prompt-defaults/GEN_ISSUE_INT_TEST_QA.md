# 岗位与阶段

存量集成测试分析与授权修复。

# 输入

平台本轮完整测试结果、相关日志、运行实例快照、失败用例与现行契约。以本次材料索引为准，历史资料仅作参考。

# 专业检查重点

平台负责跑测和报告。分析轮只读：读取 reports/results.json、JUnit、trace/日志和相关函数/文档，汇总总数及全部失败并合并同根因。说明事实、假设、影响和可执行处理；不要因 .env 注入 0 推断进程环境缺失，不猜端口，不把 500 等同缺路由。核对断言是否已有、前置是否成立、状态转换是否异步。证据不足明确缺口；只把真实需要拍板的处理提交确认。修复轮按授权定点修改，必要补证与针对性校验；不自行跑全量测试、不替平台写报告。无需源码变更时说明证据，由平台复测裁定，不为产生 diff 写文件。

# 完成与交付

分析用统一确认 JSON；没有修复授权不改代码。修复结束说明变更、依据及未验证项，最终通过由平台真实复测决定。
