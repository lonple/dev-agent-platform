# 前端代码评审规范

| 项 | 内容 |
|---|---|
| 文件 | `rule/frontend_review.md` |
| 用途 | `ada-review` FRONTEND 分片注入 |

评审 `evidence` 尽量引用规则编号（如 `FE-API-01`）。

---

## 1. 组件与结构

| 编号 | 级别建议 | 规则 |
|---|---|---|
| FE-STRUCT-01 | 中 | 单文件组件职责单一；模板过长时拆分子组件 |
| FE-STRUCT-02 | 低 | 避免在模板中写复杂表达式；抽 computed / 方法 |
| FE-STRUCT-03 | 中 | 列表渲染必须稳定 `key`，禁止用随机数当 key |

## 2. API 与数据

| 编号 | 级别建议 | 规则 |
|---|---|---|
| FE-API-01 | 高 | 请求/响应字段与后端契约一致；改字段须同步 |
| FE-API-02 | 中 | 异步请求需处理 loading / 错误态，避免静默失败 |
| FE-API-03 | 中 | 禁止把敏感 token 写入 localStorage 明文以外的不可控位置（遵循团队约定） |

## 3. 状态与副作用

| 编号 | 级别建议 | 规则 |
|---|---|---|
| FE-STATE-01 | 中 | 副作用放在约定生命周期；组件卸载应清理定时器/订阅 |
| FE-STATE-02 | 低 | 避免不必要的深层响应式大对象 |

## 4. 安全与可访问

| 编号 | 级别建议 | 规则 |
|---|---|---|
| FE-SEC-01 | 高 | 禁止 `v-html` 渲染未消毒的用户输入 |
| FE-A11Y-01 | 低 | 可交互元素应可键盘聚焦；图标按钮需 aria-label |
