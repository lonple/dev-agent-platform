# DAP 平台 UI 主题说明

## 1. 文档定位

本文档定义 DAP 平台的视觉主题基线，供前端研发直接落地到 Element Plus 主题变量和 CSS 变量中。覆盖色彩、字体、间距、组件规范、深浅模式、Agent 对话区特殊处理。

**原则**：功能验证阶段以“结构清晰、不返工”为目标，不做装饰性设计；所有视觉规则以 Token 形式定义，禁止在页面里写死颜色和间距。

## 2. 设计定位

DAP 的用户包含产品经理、架构师、研发、测试四类角色，不是纯开发者工具。主题需要同时满足：

- 长时间办公视觉负担低，非技术角色可读性好
- 流程状态、审批门禁、当前节点这些关键信息一眼可辨
- 有明确的层级纪律，避免落入 Element Plus 默认模板感

**风格方向**：灰白极简基底 + 单一克制强调色 + 严格灰阶层级。借用 Linear / Vercel 的结构纪律（排版、留白、色彩克制），不套用其深色极客皮肤。

## 3. 色彩体系

### 3.1 灰阶（页面基底与层级）

所有页面背景、卡片、分割线、文字层级全部由灰阶承担，不引入多余色相。

| Token | 色值 | 用途 |
|---|---|---|
| `--dap-gray-0` | `#FFFFFF` | 卡片、弹窗、输入框背景 |
| `--dap-gray-50` | `#F7F8FA` | 页面主背景 |
| `--dap-gray-100` | `#F0F2F5` | 次级背景、表头、禁用态背景 |
| `--dap-gray-200` | `#E5E7EB` | 分割线、边框 |
| `--dap-gray-300` | `#D1D5DB` | 输入框边框、弱化图标 |
| `--dap-gray-500` | `#8C8C8C` | 次要文字、占位符 |
| `--dap-gray-700` | `#4B5563` | 正文文字 |
| `--dap-gray-900` | `#1F2329` | 标题、关键信息 |

**规则**：页面背景用 `gray-50`，内容区用 `gray-0` 区分层级；分割线只用 `gray-200`；正文只用 `gray-700` 和 `gray-900` 两级，不引入第三级文字色。

### 3.2 品牌强调色

全站只用一个强调色，用于主按钮、当前节点高亮、选中态、关键链接。

| Token | 色值 | 用途 |
|---|---|---|
| `--dap-primary` | `#2B5AED` | 主按钮、当前节点、选中态 |
| `--dap-primary-hover` | `#1E4BD6` | 主按钮 hover |
| `--dap-primary-light` | `#EAF0FF` | 选中项背景、标签底色 |

**规则**：强调色覆盖面积不超过页面视觉面积的 10%。禁止用强调色做大面积背景、渐变、装饰性色块。

### 3.3 状态色

状态色只用于状态标签、流程节点、审批结果，且必须配合文字或图标，不能只靠颜色区分。

| 状态 | Token | 色值 | 底色 | 场景 |
|---|---|---|---|---|
| 待处理 / 待评审 | `--dap-warning` | `#D97706` | `#FEF3E2` | 评审待评、待审批 |
| 进行中 | `--dap-info` | `#2B5AED` | `#EAF0FF` | 节点进行中、Agent 生成中 |
| 已完成 / 已通过 | `--dap-success` | `#16A34A` | `#E8F7EE` | 审批通过、评审已评、回归通过 |
| 已驳回 / 有异议 | `--dap-danger` | `#DC2626` | `#FDECEC` | 审批驳回、评审有异议、bug 未关闭 |
| 已冻结 / 只读 | `--dap-neutral` | `#6B7280` | `#F0F2F5` | PRD/概设/详设冻结态 |

**规则**：审批门禁相关状态（未解决异议、未审批）必须使用 danger 或 warning，且审批按钮置灰时要有 tooltip 说明原因。

### 3.4 深色模式（可选，非 MVP 默认）

深色模式不作为 MVP 默认，但 Token 预留，后续可切换。

| Token | 浅色模式 | 深色模式 |
|---|---|---|
| `--dap-bg-page` | `#F7F8FA` | `#161616` |
| `--dap-bg-card` | `#FFFFFF` | `#1F1F1F` |
| `--dap-border` | `#E5E7EB` | `#2E2E2E` |
| `--dap-text-primary` | `#1F2329` | `#E8E8E8` |
| `--dap-text-secondary` | `#8C8C8C` | `#9A9A9A` |
| `--dap-primary` | `#2B5AED` | `#5B7FFF` |

深色模式使用近黑底色 `#161616`，不使用纯黑 `#000000`，不使用高饱和霓虹色。

## 4. 字体

| Token | 值 | 用途 |
|---|---|---|
| `--dap-font-family` | `-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif` | 全站默认 |
| `--dap-font-mono` | `"JetBrains Mono", "SF Mono", Consolas, monospace` | 代码块、commit hash、分支名、日志 |
| `--dap-font-size-xs` | `12px` | 辅助信息、时间戳、标签 |
| `--dap-font-size-sm` | `13px` | 次要正文、表格内容 |
| `--dap-font-size-base` | `14px` | 正文默认 |
| `--dap-font-size-lg` | `16px` | 小节标题 |
| `--dap-font-size-xl` | `20px` | 页面标题 |
| `--dap-font-weight-normal` | `400` | 正文 |
| `--dap-font-weight-medium` | `500` | 小节标题、按钮文字 |
| `--dap-font-weight-bold` | `600` | 页面标题、关键数字 |

**规则**：正文行高 `1.6`；标题行高 `1.4`；代码块和分支名一律用 `--dap-font-mono`。

## 5. 间距与圆角

### 5.1 间距

基于 4px 网格。

| Token | 值 | 用途 |
|---|---|---|
| `--dap-space-1` | `4px` | 图标与文字间距 |
| `--dap-space-2` | `8px` | 标签内边距、紧凑元素间距 |
| `--dap-space-3` | `12px` | 表单项内部间距 |
| `--dap-space-4` | `16px` | 卡片内边距、常规元素间距 |
| `--dap-space-5` | `24px` | 区块间距 |
| `--dap-space-6` | `32px` | 页面级区块间距 |

### 5.2 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--dap-radius-sm` | `4px` | 标签、输入框、按钮 |
| `--dap-radius-md` | `8px` | 卡片、弹窗 |
| `--dap-radius-lg` | `12px` | 大面板、对话容器 |

**规则**：不使用全圆角（pill）做主要按钮，不使用大圆角（16px 以上）做卡片。

## 6. 组件规范要点

### 6.1 按钮

- **主按钮**：仅用于页面唯一的主要动作（提交评审、审批通过、提交分支）。一个页面内主按钮不超过一个。
- **次按钮**：默认边框按钮，用于次要动作（保存草稿、取消）。
- **危险按钮**：用于驳回、删除，必须二次确认。
- **禁用态**：审批按钮在存在未解决异议时禁用，禁用态必须配 tooltip 说明“存在 N 条未解决异议”。

### 6.2 状态标签

统一使用小尺寸标签，左侧带状态圆点，格式为“圆点 + 文字”。禁止仅用颜色块区分状态。

### 6.3 表格

- 表头背景 `--dap-gray-100`，文字 `--dap-gray-700`，字重 500
- 行高 `48px`，单元格内边距 `--dap-space-3` 和 `--dap-space-4`
- 不使用斑马纹，用 hover 背景 `--dap-gray-50` 区分
- 操作列固定在右侧

### 6.4 流程节点展示

评审审批流程用横向步骤条展示：`节点名 + 状态 + 负责人`。当前节点用强调色高亮，已完成节点用 success 色，未开始节点用 gray-300。步骤条下方展示该节点的评审意见汇总入口。

### 6.5 表单

- 标签右对齐，宽度固定 `120px`
- 必填项用 danger 色星号
- 验收标准使用可增删的列表控件，每条包含“描述 + 是否可判定”勾选项

## 7. Agent 对话区特殊处理

Agent 对话是 DAP 与其他管理后台的差异点，需要局部差异化，但不做装饰性效果。

| 要素 | 规范 |
|---|---|
| 容器背景 | `--dap-gray-50`，圆角 `--dap-radius-lg`，边框 `--dap-border` |
| 用户消息 | 右对齐，背景 `--dap-primary-light`，文字 `--dap-gray-900` |
| Agent 消息 | 左对齐，背景 `--dap-gray-0`，左侧 3px 竖线用 `--dap-primary` 标识 |
| 流式输出 | Agent 消息生成中显示光标闪烁，不显示“加载中”遮罩 |
| 消息间距 | `--dap-space-4` |
| 产物卡片 | Agent 生成的 PRD/概设/详设以卡片形式嵌在对话中，卡片可点击查看详情 |
| 代码块 | 背景 `--dap-gray-100`，等宽字体，可复制 |

**禁止**：渐变气泡、发光边框、毛玻璃背景、装饰性模糊、AI 生成的通用渐变球体头像。这些属于“AI 设计痕迹”，已进入审美疲劳阶段。

## 8. 关键页面视觉要求

| 页面 | 视觉重点 |
|---|---|
| 需求列表 | 状态标签 + 当前节点 + 待办人三列必须一眼可辨；支持按阶段筛选 |
| 需求会话页 | 对话区占主视觉，右侧可折叠产物预览；流式输出不做全屏 loading |
| PRD 详情页 | 结构化字段分区展示；验收标准列表编号清晰；版本切换器固定在顶部 |
| 评审工单页 | 每个角色的评审意见独立分区；有异议项用 danger 色标记；汇总区在底部 |
| 审批面板 | 评审汇总 + 未解决异议数置顶；审批按钮禁用态必须有原因说明 |
| 任务看板 | 按阶段分列；卡片显示需求标题、当前节点、负责人、停留时长 |

## 9. 实现方式

### 9.1 Token 落地

在 `src/styles/tokens.css` 中定义全部 CSS 变量，`src/styles/element-override.scss` 中把 Element Plus 的 SCSS 变量映射到 DAP Token：

```scss
// element-override.scss
@use "element-plus/theme-chalk/src/common/var.scss" with (
  $colors: (
    "primary": ("base": #2B5AED),
    "success": ("base": #16A34A),
    "warning": ("base": #D97706),
    "danger":  ("base": #DC2626),
  ),
  $text-color: (
    "primary": #1F2329,
    "regular": #4B5563,
    "secondary": #8C8C8C,
  ),
  $border-color: (
    "base": #E5E7EB,
  ),
  $border-radius: (
    "base": 4px,
  )
);
